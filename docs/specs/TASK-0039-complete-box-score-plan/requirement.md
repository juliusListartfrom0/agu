# Requirement

Plan an AGU implementation for complete player box scores covering two-point
and three-point attempts/makes, rebounds, blocks, assists, and steals. The plan
must combine traditional computer vision/OCR, detector/tracker adapters, an
on-device VLM, and Codex acting as an offline reviewer and manual annotator.

The plan must preserve AGU's Python/FastAPI analysis boundary, v3 preprocessing,
stable API compatibility, open-source component governance, local execution,
and auditable outputs.
