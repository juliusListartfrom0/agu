# Requirement

Use public, non-commercial basketball research assets to unblock AGU's own
traditional-model plus VLM recognition. Codex may annotate training/enrollment
assets and independently evaluate frozen predictions, but must not provide
runtime event, identity, or statistics answers.

Acceptance requires a license-aware source catalog, at least two independent
full-game benchmark candidates, disjoint enrollment media with complete active
roster coverage, truthful media availability gates, sealed provenance, and tests
that prevent answer assets from becoming runtime-consumable.
